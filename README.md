# 企鹅港湾

[打开网页试玩](https://37lhm32ajjt6xnawqoz.traesite.cn/)

一只住在耳机盒里的桌面企鹅。点击它聊天、点歌、看歌词，企鹅的日常和你的消息出现在同一条时间线上。网页使用预设对话与原创旋律。

[企鹅港湾桌面客户端 · Windows / macOS](desktop/) 包含耳机联动、聊天记录、点歌和歌词的实现。美术素材、模型权重、账号配置与真机抓包另行管理。查看网页实现请打开 [网页试玩源码](desktop/web/desktop-demo.html)。Windows 真机联调请将环境变量 OPPO_BLUETOOTH_ADDRESS 设为自己的耳机地址。
